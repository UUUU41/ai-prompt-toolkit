# AI Prompt Toolkit

Copy a prompt, replace the [PLACEHOLDERS] with your own details, and paste it into any AI chat tool. Tip: give context, set a role, and ask for a clear format.

---

## Study Prompts

### 1. Explain Simply

```text
Explain [TOPIC] to me as if I am a [LEVEL, e.g. beginner / class 10 student].
Use simple language, one everyday example, and finish with 3 quick questions to test my understanding.
```

### 2. Make a Study Plan

```text
I have [NUMBER] days to prepare for [EXAM/TOPIC]. I can study [HOURS] hours a day.
Make a day-by-day study plan with topics, short revision tasks and one practice test each week.
```

### 3. Summarise Notes

```text
Summarise the following notes in bullet points, keeping only the important facts and definitions:

[PASTE YOUR NOTES HERE]
```

### 4. Quiz Me

```text
Quiz me on [TOPIC]. Ask one question at a time, wait for my answer, then tell me if I was right and explain the correct answer before asking the next question.
```

### 5. Fix My Mistakes

```text
Here is my answer to a question about [TOPIC]:

[PASTE YOUR ANSWER HERE]

Point out the mistakes, explain why they are wrong, and show the corrected answer.
```

## Coding Prompts

### 6. Explain Code

```text
Explain what this [LANGUAGE] code does, line by line, in simple terms:

[PASTE YOUR CODE HERE]
```

### 7. Debug an Error

```text
I am getting this error in [LANGUAGE]:

[PASTE THE ERROR MESSAGE HERE]

Here is my code:

[PASTE YOUR CODE HERE]

Explain what is causing the error and show the fixed code.
```

### 8. Write a Function

```text
Write a [LANGUAGE] function that [WHAT IT SHOULD DO].
It should take [INPUTS] and return [OUTPUT]. Add comments explaining each step and give 2 example uses.
```

### 9. Improve My Code

```text
Review this [LANGUAGE] code and suggest improvements for readability, performance and error handling. Show the improved version and list what you changed and why:

[PASTE YOUR CODE HERE]
```

### 10. Learn a Concept

```text
Teach me [PROGRAMMING CONCEPT] in [LANGUAGE]. Start with a simple explanation, then show a short working example, then give me a small exercise to try myself.
```

## Content Creation Prompts

### 11. Brainstorm Ideas

```text
Give me 10 ideas for [TYPE OF CONTENT, e.g. a blog post / video] about [TOPIC].
The audience is [AUDIENCE]. For each idea, add a one-line description and a catchy title.
```

### 12. Write a Draft

```text
Write a [LENGTH, e.g. 300-word] [TYPE OF CONTENT] about [TOPIC] for [AUDIENCE].
Use a friendly tone, short paragraphs and a clear heading structure.
```

### 13. Improve My Writing

```text
Improve this text. Fix the grammar and spelling, make it clearer and more engaging, and keep the same meaning:

[PASTE YOUR TEXT HERE]
```

### 14. Make It Shorter

```text
Rewrite this text in about half the words, without losing the main points:

[PASTE YOUR TEXT HERE]
```

### 15. Social Media Captions

```text
Write 5 short captions for [PLATFORM] about [TOPIC]. Make them friendly, add one relevant hashtag each, and end one of them with a question to encourage replies.
```

---

## How to Write Better Prompts

- Be specific: say what you want, who it is for and how long it should be.
- Give context: share the background, your level or the goal.
- Set a role: for example, "Act as a patient maths teacher."
- Ask for a format: bullet points, a table, steps or a story.
- Check the answer: AI can be wrong, so verify important facts.
