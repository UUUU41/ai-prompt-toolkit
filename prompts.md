# 🤖 AI Prompt Toolkit — 15 Ready-to-Use Prompt Templates

A collection of complete, practical AI prompt templates for **study, coding and content writing**.
Just copy a prompt, replace the `[BRACKETED]` parts with your own details, and paste it into any AI chat tool (ChatGPT, Claude, Gemini, etc.).

---

## 📚 Study & Learning

### 1. Explain Like I'm a Beginner
**When to use:** Starting a brand-new topic you know nothing about.

```
Explain [TOPIC] to me in simple words, as if I am a complete beginner. Use one real-life example and one simple analogy. After the explanation, give me a 3-line summary and 3 practice questions (easy, medium, hard) to test my understanding. Do not give the answers to the practice questions.
```

### 2. Feynman Technique Coach
**When to use:** Checking whether you truly understand a topic, not just memorised it.

```
I am learning [TOPIC] using the Feynman Technique. I will explain it to you in my own words below. Read my explanation, point out any gaps, mistakes or parts that are unclear, then explain only those weak parts again in simpler words. My explanation: [YOUR EXPLANATION]
```

### 3. Quiz Generator
**When to use:** Self-testing before an exam or a class test.

```
Create a quiz of [NUMBER] questions on [TOPIC] for a [CLASS OR EXAM LEVEL] student. Mix multiple-choice, true/false and short-answer questions. Give all the questions first without answers, then give the full answer key at the very end, separated by a line.
```

### 4. Personal Study Plan
**When to use:** Planning your preparation for an exam or a new subject.

```
Make a [NUMBER]-day study plan for me to learn [SUBJECT] from scratch. I can study [HOURS] hours per day. Divide the syllabus into daily topics, keep one day per week only for revision, and end the plan with a mock-test day. Present the plan as a day-by-day table.
```

### 5. Notes Summariser
**When to use:** Turning long notes into quick revision material.

```
Summarise the following study notes on [TOPIC] into clear revision notes. Give me: 1) key points in bullet form, 2) important definitions, 3) formulas or facts I must memorise, and 4) five likely exam questions from these notes. Notes: [PASTE YOUR NOTES]
```

## 💻 Coding & Development

### 6. Line-by-Line Code Explainer
**When to use:** Trying to understand code written by someone else (or generated by AI).

```
Explain the following [PROGRAMMING LANGUAGE] code to me line by line in simple words. Then tell me: what the code does overall, its time complexity, and one way the code could be improved. Code: [PASTE YOUR CODE]
```

### 7. Bug Finder and Fixer
**When to use:** Your code runs but gives the wrong output or an error.

```
The following [PROGRAMMING LANGUAGE] code has a bug. The expected behaviour is: [EXPECTED BEHAVIOUR]. The actual behaviour is: [ACTUAL BEHAVIOUR OR ERROR MESSAGE]. Find the bug, explain in simple words why it happens, and give me the corrected full code. Code: [PASTE YOUR CODE]
```

### 8. Friendly Code Reviewer
**When to use:** Polishing working code before submitting an assignment or pushing it to GitHub.

```
Review the following [PROGRAMMING LANGUAGE] code like a senior developer reviewing a junior's work. Point out problems in readability, naming, duplication and edge cases. For each problem, show the improved version of that part. Be encouraging, not rude. Code: [PASTE YOUR CODE]
```

### 9. Build a Function from a Description
**When to use:** You know what you want the code to do but not how to write it.

```
Write a function in [PROGRAMMING LANGUAGE] that does the following: [DESCRIBE WHAT THE FUNCTION SHOULD DO]. Include input validation, clear comments, and 3 example test cases with expected outputs. Explain your approach in 3-4 lines after the code.
```

### 10. Code Language Converter
**When to use:** Moving a program or snippet from one programming language to another.

```
Convert the following code from [SOURCE LANGUAGE] to [TARGET LANGUAGE]. Keep the logic exactly the same, use the target language's normal style and naming conventions, and add a short note listing anything that works differently in the target language. Code: [PASTE YOUR CODE]
```

## ✍️ Content & Writing

### 11. Paragraph Rewriter
**When to use:** Improving drafts, messages or assignments without changing their meaning. In `[TONE]`, write friendly, formal or simple.

```
Rewrite the following text in a [TONE] tone. Keep the meaning and all facts the same, keep roughly the same length, and make it easy to read. Give me 2 versions to choose from. Text: [PASTE YOUR TEXT]
```

### 12. Blog Post Writer
**When to use:** Starting a blog article without staring at a blank page.

```
Write a blog post of about [WORD COUNT] words on the topic '[BLOG TOPIC]' for [TARGET AUDIENCE]. Start with a catchy title and a hook introduction, use clear subheadings, include practical tips or examples in the middle, and end with a short conclusion and one call to action.
```

### 13. Social Media Caption Generator
**When to use:** Posting a photo or update on Instagram or other social media.

```
Write 5 different Instagram captions for a post about [POST TOPIC]. Make them a mix of: one funny, one motivational, one informative, one short (under 10 words) and one question that invites comments. Add 5 relevant hashtags to each caption and a few matching emojis, but do not overdo the emojis.
```

### 14. Professional Email Writer
**When to use:** Writing formal emails to teachers, companies or officials that you don't want to get wrong. In `[RECIPIENT]`, write who it is for, e.g. my teacher or a company HR.

```
Write a polite, professional email to [RECIPIENT] about [EMAIL PURPOSE]. My key points are: [KEY POINTS]. Keep the email under 150 words, include a clear subject line, and end with a respectful closing with space for my name.
```

### 15. Resume Bullet Improver
**When to use:** Applying for internships, jobs or freelance work.

```
Improve the following points from my resume for a [JOB OR INTERNSHIP ROLE] application. Rewrite each point starting with a strong action verb, add numbers or results where I mention them, and keep each point to one line. Points: [PASTE YOUR RESUME POINTS]
```
